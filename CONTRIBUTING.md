# Contributing

Report bugs with reproduction steps, runtime versions and bounded synthetic examples.
Keep installation configuration and generated evidence outside the source tree.
Preserve the upstream MIT license and attribution.
Use English for code and documentation; keep presentation translations in web/locales.
Run the sequential checks in README.md before proposing a change.
Do not attach operational state or generated images to source changes.
Changes to producer mutations must preserve capability checks, expected identity, previews and receipts.
